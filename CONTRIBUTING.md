# Contributing to ReMaverick

ReMaverick is a time-sensitive preservation project. Useful evidence is better than polished prose, and an imperfect observation that can be reproduced is better than an unsupported conclusion.

## Before submitting evidence

Record:

- Date and time in UTC
- Game build and branch, where known
- Steam AppID and depot/manifest IDs where relevant
- Platform and OS version
- Proton version when using Linux
- Game mode / lobby state / host-client role
- What was being tested
- What was observed
- What was inferred, if anything
- Any relevant hashes
- AI tools used, prompts or task descriptions where practical, and what was manually verified

## Do not upload

- Game executables, DLLs, PAK/UCAS/UTOC content, or other substantial proprietary game assets
- Steam credentials, account tokens, authentication codes, or session cookies
- Personal IP addresses belonging to other players
- Private Discord messages or support-ticket material without permission
- Anti-cheat bypasses, evasion techniques, cheats, or instructions for disabling security controls

Publicly observable endpoints may be recorded when technically necessary, but redact personal/home addresses and player-identifying data before publication.
